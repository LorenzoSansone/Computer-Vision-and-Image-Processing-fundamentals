# 📸 Computer Vision & Image Processing

This repository contains exercises and implementations focused on the fundamentals of **Computer Vision and Digital Image Processing**.

The goal is to explore and understand core image processing techniques, starting from basic image manipulations to fundamental edge detection algorithms.

---

## 📌 Topics Covered

### 🖼️ Basic Image Processing
- Image loading and visualization
- Color space conversion (RGB, Grayscale, etc.)
- Resizing and cropping
- Intensity transformations and normalization
- Histogram computation and analysis

### 🎛️ Filtering
- Linear filters (mean, Gaussian)
- Non-linear filters (median)
- 2D convolution
- Image sharpening
- Noise reduction techniques

### 🔍 Edge Detection
- Gradient-based methods (Sobel, Prewitt)
- Laplacian operator
- Canny edge detector
- Intensity discontinuity analysis

---

## 🎯 Objectives

- Understand the fundamental concepts of digital image processing  
- Implement classical image processing algorithms  
- Analyze the effects of different filters on images  
- Build a solid foundation for more advanced Computer Vision applications
